# Docker Proof of Concept: Minimalist Container Evaluation

This repository provides a minimalist Proof of Concept (POC) designed for an academic comparison between **Docker** and **WebAssembly (WASM)**.

It demonstrates the fundamental containerization characteristics outlined in *"Learn Docker in a Month of Lunches"* (Chapters 2 & 3):
- **Reproducible Packaging:** Self-contained application and runtime packaged via a custom `Dockerfile` (`FROM`, `WORKDIR`, `COPY`, `EXPOSE`, `CMD`).
- **Container Isolation:** Independent hostname (Container ID), isolated OS environment (`os.platform()`, `os.arch()`), and isolated container time generation.
- **Portability & Footprint:** Compact base image (`node:20-alpine`) enabling quick inspection of image size and resource overhead.

## Commands

All commands below should be executed from within the `Docker` directory:

```bash
cd Docker
```

### 1. Build the Docker Image
Packages the Node.js application and runtime into a Docker image tagged `hello-docker`:

```bash
docker image build -t hello-docker .
```

### 2. Run the Container in Background
Runs the container in detached mode (`-d`), mapping host port `8088` to container port `8080`, with the container name `hello-docker-app`:

```bash
docker container run -d -p 8088:8080 --name hello-docker-app hello-docker
```

Once running, verify the application in your browser or with curl:
- **Browser:** [http://localhost:8088](http://localhost:8088)
- **Curl:** `curl http://localhost:8088`

The page displays:
- **Title:** `Hello World from Docker!`
- **Container Hostname:** Container ID generated by Docker's namespace isolation.
- **Platform & Architecture:** `linux / x64` (or `arm64`).
- **Container Date & Time:** Generated timestamp within the container environment.
- **Response Time:** Request processing duration in milliseconds.

### 3. Inspect Image Size
Check the size of the built image on disk:

```bash
docker image ls hello-docker
```

### 4. Inspect Resource Consumption
Check instant CPU, memory, and network utilization without continuous streaming:

```bash
docker container stats --no-stream hello-docker-app
```

### 5. Clean Up Container
Stop and forcefully remove the running container:

```bash
docker container rm -f hello-docker-app
```

*(Optional) Remove the built image when finished:*

```bash
docker image rm hello-docker
```

## Academic Comparison Context (Docker vs. WebAssembly)

| Metric / Dimension | Docker (Container) | WebAssembly / WASI (Module) |
| :--- | :--- | :--- |
| **Packaging Unit** | OCI Container Image (OS layer + runtime + app) | Standalone `.wasm` bytecode binary |
| **Isolation Mechanism** | Linux Namespaces, cgroups, chroot/seccomp | Capability-based sandboxing, memory-safe VM |
| **Typical Image Size** | ~50 MB – 150 MB (`node:20-alpine` ~130 MB) | < 1 MB – 5 MB |
| **Startup / Cold-start** | ~100 ms – 1000 ms (OS init + process spawn) | Sub-millisecond (~1 ms – 10 ms) |
| **Host Independence** | Requires container engine (Docker / containerd) | Runs on any Wasm runtime (Wasmtime, Wasmer, Node) |
